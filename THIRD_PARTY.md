`app/src/main/assets/site-outline.tsv` records public course section labels matched to existing torrent file indexes. Sources and matching rules: [website layout notes](docs/website-layout.md). It contains no video, tests, textbooks, account data, or unavailable lesson placeholders.

`app/src/main/assets/lessons.torrent` is the torrent metadata supplied by the repository owner. No ownership of the referenced videos is asserted. Video files are not distributed in this repository or APK.
